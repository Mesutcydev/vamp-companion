Run local models on your Mac and use them from the existing Vamp Assistant app on iPhone and iPad. The Mac companion keeps setup simple: Models, Devices, and Settings.

The iOS download is not published yet. Pair your existing sideloaded Vamp Assistant build.

Apple Silicon · macOS 15 or later · Developer ID signed and notarized

Models

Download models for your Mac, import existing model files, and connect API providers. Your iPhone can choose the model for each session.

Devices

Scan a pairing code once. Connect over trusted local Wi-Fi or use Tailscale when you’re away from home.

Settings

Manage credentials, updates, and optional sharing or Mac control. Close the window and the companion keeps running.

Start in three steps

  1. Unzip the download and move Vamp Companion.app to Applications.
  2. Add a model in Models or configure an API provider in Settings.
  3. Open Devices, enable iPhone access, and scan the pairing code in Vamp Assistant on iOS.

Your existing iOS assistant features remain available, including sessions, tools, approvals, bots, and optional Mac control. The Mac must remain running and reachable.

App Stream 1.0 build 12 recognizes Companion QR codes from Scan Mac QR Code on the home screen. The address and code are filled in; tap Pair Mac to connect. In Devices, choose Local Wi-Fi for the same network or Tailscale for remote access. Both App Stream editions support your private tailnet; connect both devices to Tailscale. It is available to invited testers in TestFlight.

Vamp Companion installs alongside the full Vamp Assistant Mac app with separate data, credentials, and updates.
