# Vamp Companion 0.1.9 (13)

A new look that matches the iPhone app, plus everything from 0.1.8, which was
only published as a DMG preview and never offered as an automatic update.

- One compact glass toolbar holds the Vamp logo, a Models / Devices / Settings
  switcher, and a live status for iPhone access.
- Labels are sentence case; cards and buttons are softer and use the same
  system greys as the iPhone app.
- Bundled llama.cpp and Prism compatibility runtimes, so GGUF support arrives
  with the update.
- LFM3 Omni media tools: workspace audio transcription and translation, image
  questions, video frames with their soundtrack, and WAV speech generation.
  Video decoding requires ffmpeg in PATH.
- Bonsai 2 packed PQ2_0/PTQ1_0 GGUF files select the Prism runtime by metadata.
- MLX Swift 0.32.3 and MLX Swift LM 3.32.3.

Existing model files, settings, and paired devices are kept.
